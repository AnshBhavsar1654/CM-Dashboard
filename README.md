# CM Outreach Insights Dashboard

A dashboard for visualizing CM Outreach Activities in Gujarat, built with Next.js, Recharts, and Leaflet maps.

## Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS + shadcn/ui
- **Charts:** Recharts
- **Maps:** Leaflet + React-Leaflet
- **Database:** PostgreSQL (via `pg`)
- **Deployment:** Vercel

## Getting Started

```bash
npm install
npm run dev
```

The app runs at [http://localhost:9002](http://localhost:9002).

## Environment Variables

Create a `.env` file with your PostgreSQL connection string and any other required secrets.

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start dev server |
| `npm run build` | Production build |
| `npm run start` | Start production server |
| `npm run lint` | Run linter |
| `npm run add-user` | Add a user to the database |
